# clone-tabnews

Implementação do [TabNews](http://www.tabnews.com.br) desenvolvida no curso.dev. Um projeto educacional que replica a funcionalidade de uma plataforma de compartilhamento de notícias com autenticação, gerenciamento de usuários e sistema de ativação.

## 🚀 Principais Tecnologias

- **Frontend**: Next.js 14, React 18, SWR
- **Backend**: Next.js API Routes, Node.js
- **Banco de Dados**: PostgreSQL
- **Autenticação**: bcryptjs, JWT via cookies
- **Email**: Nodemailer
- **Testes**: Jest
- **Infraestrutura**: Docker, Docker Compose
- **Hospedagem**: Vercel (frontend), Neon.tech (banco de dados)

## 📋 Recursos Principais

- Autenticação e autorização de usuários
- Sistema de ativação de conta via email
- Gerenciamento de sessões
- Migrações de banco de dados automáticas
- Testes de integração completos
- Linting com ESLint e Prettier
